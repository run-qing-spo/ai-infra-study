# Paired FS/FS A/A evidence

This directory stores the immutable artifacts for the long-window crossover
qualification defined by `docs/DECISION_0002_UNSTABLE_CLOUD_READ_PATH.md`.

Raw campaigns are ignored by Git. A public result must additionally track:

- the campaign ID and campaign/summary SHA-256;
- the harness tree SHA-256;
- a sanitized per-pair metric table;
- the exact analysis output;
- an immutable archive location for the complete raw campaign.

Smoke campaigns never enter the evidence index.
