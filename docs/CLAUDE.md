# docs/ 改动须知

## 新增 / 重命名 / 删除文章时的检查清单

文章本体之外，必须同步检查以下三处，任一处遗漏都算未完成：

1. **主页**：`docs/index.md`
   - `hero.actions` 中的入口按钮（如果是重点文章）
   - "目录"区块的列表条目
2. **顶部导航栏**：`docs/.vitepress/config.ts` 中的 `nav`
3. **侧边栏目录**：`docs/.vitepress/config.ts` 中的 `sidebar`

完成改动后，向用户报告时显式说明这三处分别"已更新 / 无需更新 / 未涉及"，不要默认沉默。
